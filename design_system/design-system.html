0. Application Shell (Clone Exato)
Active Layout Shell

Esta tela é o clone estrutural exato do shell corporativo Duralux: Sidebar fixa à esquerda (.nxl-navigation, largura 260px expandida / 80px colapsada), Header fixo no topo (.nxl-header, altura 80px), e Área de Conteúdo Principal (.nxl-container / .nxl-content).

Sidebar (.nxl-navigation)
Largura: 260px (expandida) / 80px (colapsada). Logo institucional, grupos de navegação (.nxl-caption), itens multinível com setas animadas (.nxl-hasmenu).
Header (.nxl-header)
Altura: 80px. Toggles de sidebar responsivos, campo de pesquisa rápida, seletor de idioma internacional, notificações com badge pulsante e perfil de usuário.
Container (.nxl-container)
Grid responsivo fluido com padding de 30px, cards com layout stretch (.stretch.stretch-full), cabeçalhos de página com breadcrumbs integrados.
